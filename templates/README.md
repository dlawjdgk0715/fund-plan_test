# templates 폴더

아래 파일들을 여기에 복사해 넣어주세요.

    templates/자금운용계획_template.xlsm    ← 엑셀 산출용 (필수)
    templates/자금운용계획_template.pptx    ← PPT 산출용 (선택)
    templates/서식기준.xlsm                 ← 표 서식·열 너비 기준 (선택, 아래 참고)

`.pptx` 는 지난달 보고에 쓴 PPT(6장)를 그대로 넣으시면 됩니다.
없어도 엑셀은 만들어지고, PPT 옵션만 비활성화됩니다.

## 서식기준.xlsm — 손보신 서식을 계속 유지하는 방법

산출된 엑셀에서 **열 너비·표 위치·글꼴·테두리를 직접 다듬으셨다면**, 그 파일을
`templates/서식기준.xlsm` 이라는 이름으로 여기에 넣어두세요.

다음 달부터는 요약1·요약2를 새로 조립하지 않고 **그 파일의 시트를 그대로 가져다 씁니다.**
이 두 시트는 거의 전부 수식이라 숫자는 알아서 새로 계산되고, 손보신 배치는 그대로 남습니다.
앱이 갈아 끼우는 것은 세 가지뿐입니다.

| 갈아 끼우는 것 | 어떻게 찾나 |
|---|---|
| 월 표기 (7월 → 8월 …) | 머리글의 `N월(a)` / `M월(b)` 을 읽어 자동 판단 |
| 기초잔고 | '기초잔고' · '기초자금' 글자를 찾아 그 오른쪽 칸에 |
| 비고 4줄 | '비고' 열 + ' B. 수입' · ' C. 지출' 행을 찾아서 |

나머지 시트(유동자금세부·연간·자금실적)의 **열 너비·행 높이**도 이 파일을 따릅니다.

> 서식을 또 손보셨다면 그 파일로 `서식기준.xlsm` 을 덮어쓰시면 됩니다.
> 파일이 없으면 앱이 기본 배치로 만듭니다(지금까지처럼).
> 표 안에 행·열을 **추가하거나 지우는 큰 변경**을 하셨다면, 만든 뒤 숫자가 맞는지 한 번 확인해주세요.

## ⚠️ 반드시 "행 추가된" 템플릿을 쓰세요

**2026-08-25부터는 원본 그대로 넣으셔도 됩니다.** 마케팅·지급이자·외주용역비 금액이
있는데 시트에 그 행이 없으면 **앱이 산출할 때 자동으로 행을 끼워 넣습니다**
(원본 파일은 건드리지 않습니다).

원본 워크북 자체에 행을 넣어두고 싶으시면 아래 도구를 쓰시면 됩니다.

    python tools/add_marketing_row.py 원본파일.xlsm templates/자금운용계획_template.xlsm

**한 번만 실행하세요.** (이미 행이 있으면 알아서 멈춥니다)

## _fast_ 로 시작하는 파일은 지우셔도 됩니다

원본 워크북은 안 쓰는 셀 스타일이 6만 개 넘게 쌓여 있어 여는 데만 10초가 걸립니다.
앱이 처음 한 번 가벼운 사본(`_fast_자금운용계획_template.xlsm`)을 만들어 재사용합니다.
지워도 다음 산출 때 다시 만들어집니다(그 한 번만 10초쯤 걸립니다).
