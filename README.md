# 자금운용계획 자동화 웹앱

㈜카탈리스터 전략금융실 — 매달 만드는 `자금운용계획.xlsx` 작성을 자동화합니다.

접속 링크
https://fund-plantest-jutsa2bqpkdrhh6ekhedy5.streamlit.app/


> **현재 상태**: M1~M6 구현 완료 · 원본 워크북 대조 검증 통과 · 실사용 테스트 진행 중
> **미구현**: M7(확정·PPT·롤오버) · M8(동시 접근) · M9(화면 디자인)
>
> 무엇이 언제 바뀌었는지는 [CHANGELOG.md](CHANGELOG.md),
> 다음에 할 일은 [진행상황.md](진행상황.md) 를 보세요.

## 한 달 작업 흐름

```
Home에서 "실적 월"만 정하면 나머지는 자동입니다.
  실적 월 2026-07  →  7월 실적 + 8월 계획 보고서

1 실적 업로드    7월 일일자금계획.xlsx 하나만 올리면
                   · 07로 시작하는 시트 전부 합침
                   · 6월말 잔고(전월 마지막 시트) → 7월 기초잔고
                   · 7월말 잔고(당월 마지막 시트) → 8월 기초잔고
                   · 계산값 vs 실제값 자동 대조

2 계획 업로드    부서별 8월 계획서를 한꺼번에 올림 → 계정과목 확인

3 실적/계획 관리  표에서 수정 · 중복 점검 · [재계산] → 검증 6종

4 전체 미리보기   유동자금세부 표 전체 + 검증 결과

5 엑셀 산출      환율만 넣으면 엑셀 파일 생성
```

---

## 1. 처음 설치하기 (한 번만)

1. **Python 3.11 설치** — python.org에서 내려받고, 설치 화면에서 **"Add Python to PATH"** 체크
2. 이 폴더를 원하는 곳에 압축 풀기 (예: `C:\자금운용계획`)
3. 시작 메뉴에서 **명령 프롬프트**를 열고 아래를 차례로 입력

```
cd C:\자금운용계획
pip install -r requirements.txt
```

4. **원본 워크북 넣기** — 회사 PC에 있는 원본 자금운용계획 엑셀을
   `templates\자금운용계획_template.xlsm` 이름으로 복사해 넣으세요.
   (이 파일은 회사 데이터라 깃허브에 올라가지 않습니다)

## 2. 실행하기 (매번)

```
cd C:\자금운용계획
streamlit run app/Home.py
```

브라우저가 자동으로 열립니다. 안 열리면 주소창에 `http://localhost:8501`.
끝낼 때는 명령 창에서 `Ctrl + C`.

## 3. 계산이 맞는지 먼저 확인해보기

```
python tests/run_all.py
```

파서 15개 항목 + 계산 엔진(원본 워크북 실측값 대조)을 몇 초 안에 검사합니다.
`tests/test_engine.py` 는 `templates/` 에 원본 워크북이 있어야 전체가 돌아가고,
없으면 돌릴 수 있는 것만 확인하고 넘어갑니다.

## 화면 순서

| 화면 | 하는 일 |
|---|---|
| Home | 실적 월 정하기 (계획 월은 자동으로 다음 달) |
| 1 실적 업로드 | 일일자금계획.xlsx — 그 달 시트 전부 합침 |
| 2 계획 업로드 | 부서별 계획서 여러 개 한꺼번에 → 시트 선택 → 계정과목 분류 |
| 3 실적/계획 관리 | 표에서 수정 · [재계산] → 검증 6종 |
| 4 전체 미리보기 | 유동자금세부 표 전체 + 검증 결과 |
| 5 엑셀 산출 | 기초잔고·환율 입력 → 엑셀 파일 만들기 |
| 6 비고 라벨 관리 | 비고에 쓸 짧은 라벨 수정 (즉시 반영) |
| 7 태그 사전 관리 | 계정과목 자동 분류 기준(적요 예시) 관리 |

## 폴더 구조

```
app/          화면 (Streamlit)
core/         계산·파싱·산출 로직
  config.py         경로·API키 설정
  data_store.py     DB 저장/조회
  parsers.py        엑셀 읽기
  tag_classifier.py 계정과목 자동 분류
  engine.py         집계 + 검증 6종 + 운용자금 이월
  remarks_rule.py   비고 자동 작성
  remark_labels.py  비고 라벨 축약표
  recheck_items.py  매달 재확인 항목 알림
  excel_writer.py   엑셀 산출 (원본 수식 유지)
  fx.py             한국은행 ECOS 환율 조회
db/           schema.sql (테이블 정의) + seed_tags.py (태그 34개)
templates/    원본 워크북 (직접 넣어야 함)
tests/        계산 검증 스크립트
```

## 설정 바꾸기

| 무엇 | 방법 |
|---|---|
| DB를 구글드라이브 폴더에 두기 | 환경변수 `FUNDPLAN_DB` 에 경로 지정 |
| 한국은행 환율 API 키 | 환경변수 `ECOS_API_KEY` 에 지정 |
| 태그 사전 수정 | `db/seed_tags.py` 고치고 `python db/seed_tags.py --reset` |

- `db/tags.db` 에는 태그 사전·거래 기록이 쌓입니다. **업데이트할 때 이 폴더는 덮어쓰지 마세요.**
